# Algoryx Task 4 – 3D Asset Creation

A futuristic Autonomous Inspection Drone created using Blender as part of my Algoryx internship.

## Project Overview

This project focuses on creating an original 3D asset for inspection applications.

The drone is designed as a conceptual autonomous inspection system with a futuristic structure and multiple inspection components.

## Features

- Futuristic drone body
- Four motor arms
- Four propellers
- Inspection camera
- Radar sensor
- Side inspection sensors
- LED lighting
- Battery compartment
- Landing gear
- Detailed body panels

## Software Used

- Blender
- GLB / glTF

## Files

- `Smart_Inspection_Drone.blend` – Blender source file
- `Smart_Inspection_Drone.glb` – Exported 3D asset
- `screenshots/` – Different views of the 3D model
